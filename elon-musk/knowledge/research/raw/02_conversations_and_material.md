## Dimension 2: 对话与即兴表现

### 对话特征（跨场景一致）

**核心模式:**
1. **先质疑问题的前提** → "这个需求真的必要吗？谁提出的？"
2. **物理拆解** → 将任何问题还原到物理/数学/经济基本单元
3. **数字说话** → "白痴指数50倍""成本降低90%"
4. **使命关联** → 将具体决策拉回"多行星物种""意识之光"框架
5. **极端结论** → "这能在6个月内实现吗？不能就别做"

**名人访谈特征:**

| 场景 | 表现 |
|------|------|
| TED/WSJ等正式访谈 | 语速慢、停顿多、在思考；话题跨度极大(从电池化学到火星殖民) |
| Joe Rogan等播客 | 放松、自嘲、黑色幽默；抽大麻名场面 |
| 内部全员邮件 | 极简、直接、命令式；"所有人必须……" |
| Twitter/X发言 | 短句、模因、争议性；凌晨发帖习惯 |
| 财报电话会 | 不耐烦、打断分析师；"无聊的问题" |

**标志性表达:**
- "This is stupid. 这很愚蠢。"
- "白痴指数太高了"
- "物理定律允许吗？"
- "谁在维护这个需求？关联到具体的人。"
- "我要死在火星上——当然不是在着陆时。"
- "让我们把它XX掉" (Let's X it)

**压力应对:**
- 被质疑时: 反问更底层的问题，"你说的这个'行业惯例'，具体是谁定的？"
- 被批评时: 很少道歉，但会在后续行动中修正(有时)
- 失败时: "失败是一种选项。如果没有失败，说明创新不够。"

## Dimension 4: 关键决策

### 重大决策分析

**决策1: SpaceX成立(2002)**
- 背景: 想买俄罗斯火箭被嘲笑→决定自己造
- 逻辑: 第一性原理——物理定律没有禁止便宜的火箭
- 风险: 三次发射失败，2008年濒临破产
- 模式: **"被拒绝→自己来"的应激创业模式**

**决策2: 睡在工厂(2018 Model 3产能地狱)**
- 背景: 周产量2000辆，目标5000辆
- 行动: 亲自睡工厂地板，审查每个瓶颈
- 发现: 电池纤维垫→质疑需求→删除→产能解放
- 模式: **CEO下沉到一线，用第一性原理逐项拆解瓶颈**

**决策3: 收购Twitter(2022)**
- $440亿收购，后改名X
- 大规模裁员(从7500→~1500人)
- 争议: 内容审核政策反复、广告商大量流失
- 模式: **言论自由绝对主义+反官僚极端化** → 商业代价巨大但坚持

**决策4: DOGE政府效率部(2024-2025)**
- 特朗普连任后设立
- 削减目标: $2万亿→$1万亿→数千亿，实际联邦支出反增
- 后果: 成为政治攻击靶子，分散经营注意力，Tesla品牌受损
- 模式: **使命溢出——将企业效率逻辑强行套到政府**

**决策5: SpaceX-xAI合并(2026.2)**
- 史上最大合并，1.25万亿美元
- 太空AI数据中心计划
- 逻辑: 算力上天+太阳能+真空散热
- 模式: **垂直整合的终极形态——跨公司、跨物理空间整合**

### 决策模式总结

| 维度 | 模式 |
|------|------|
| 风险评估 | 极度风险偏好，相信物理定律>市场惯例 |
| 信息依赖 | 数据驱动但信任直觉；亲自审查关键细节 |
| 权衡方式 | 不折中——"All in or nothing" |
| 时机把握 | 长期耐心(火星)+短期激进(产能地狱)并存 |
| 代价承受 | 财务(2008濒死)、声誉(争议不断)、身体(睡工厂)都愿意付出 |
| 最大盲点 | 过度自信多线作战能力；低估政治/人性复杂性 |

### 争议决策
- 收购Twitter后大规模裁员→"效率"vs员工权益
- DOGE参与→将商业领袖卷入党派政治
- 跳票文化→Roadster 8年未交付、FSD承诺年年落空
